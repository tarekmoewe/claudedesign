# Claude Design

A repository for design skills and guidelines for Claude.

## Skills

### Frontend Design

Guidance for distinctive, intentional visual design when building new UI or reshaping an existing one. This skill helps with:

- Aesthetic direction
- Typography choices
- Avoiding generic/templated designs
- Design principles (hero, structure, motion, complexity)
- Writing intentional copy
- Process and self-critique

See `.github/skills/frontend-design/SKILL.md` for the full skill documentation.

## Usage

These skills are designed to be used with Claude to provide specialized guidance on design-related tasks.
